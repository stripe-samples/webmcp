# Contributing

Thanks for contributing to this Stripe sample!

## Code of Conduct

All interactions with this project follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Filing Issues

Issues should be relevant to this sample repository specifically. For broader questions or issues:

- [Stripe Support](https://support.stripe.com/)
- [Stripe Discord](https://stripe.com/go/developer-chat)

## Code Review

All submissions, including those by project members, require review. We use GitHub pull requests for this purpose.

## Development

Keep each sample's setup and run instructions in its README, including prerequisites,
required environment variables, and any browser configuration needed to use WebMCP.

Use Stripe test credentials when developing samples. Keep credentials in local
environment files and out of version control.

### Testing

Before submitting a PR, ensure:

1. Any lint, formatting, type checking, and test commands documented by the sample pass.
2. The sample runs successfully with test credentials.
3. Setup and run instructions reflect your changes.

CI checks repository whitespace and runs each sample's lint, formatting, and type
checks. See the sample's README for local commands.
